# 1989 年《軟體世界》第 19 期攻略整理

來源：《軟體世界》第 19 期（1989），第 28 到 37 頁，共十頁。
署名兩篇：第 28 頁「提示篇」署名「德&波」，第 29 到 37 頁「攻略」署名「小瓜瓜」。

⚠ **頁碼對照**：issue #38 給的網址編號 29 到 38，對應的是版面上印的第 28 到 37 頁，差一頁。
本文一律用**版面印的頁碼**。檔名與版面頁碼的對照是 `檔名 − 1 ＝ 版面頁碼`。

本文只整理事實性資料（地點、路線、道具、密碼、數值、流程順序），不轉錄原文。
原文的評論與心得只在必要時以一句話轉述並標明出處。掃描圖不進版控，放在 `workplace/walkthrough-1989/`。

## 2. 提示篇：一般玩法

### 2.1 征途上

| # | 要點 |
|---|---|
| 1 | 實力不足時不要見人就打。 |
| 2 | 各衛星站有先前派去的超能戰士可召集入隊。Pospopoi 體力強但超能力為零，原文建議不要收；若已入隊就排在隊伍最前面擋傷害。 |
| 3 | 遇到隊友按 **F2** 搭話，內容常是道具位置或房間用途的線索。 |
| 4 | 判別房間功用：進去後沒出現選單多半沒作用；有選單就先退出存檔（SAVE）再進去，失手可以重來。 |
| 5 | SAMAR 內有一處 Bio Room，可取得 3 個 Yontry，也可在此休息治療。 |
| 6 | Bio Sleep Room 可暫存隊友、更換隊友順序。 |
| 7 | 隊伍最好每人都有 Marker 與 Mind-Jump。一人只能 Marker 一個地點；在衛星站出口先 Marker，之後可直接搭船飛往別站，不必再走進去找出口。 |
| 8 | 儘快找齊 Koorak、Loran、Chia B，讓 Kayla 發揮作用。 |

### 2.2 戰鬥時

| # | 要點 |
|---|---|
| 1 | 敵人的超能力數值等於它的體力，所以打掉體力就等於解決超能力。敵方總合太高時先用防護罩拖，等它耗損再反擊。敵人投降後可選逼問或複製：逼問能套出情報但必須放走；複製需要隊中有人會 Duplicate，全隊變成該敵外形後會被敵軍當同伴，但己方看到你也會誤認，且此時不能中止變身。 |
| 2 | 能量匣只對特定怪物有大傷害或一次消滅，對別的怪物幾乎無效。文章只確認 **Gamera 對 Anbaddin** 有效，且是瞬殺。沒有 Turbo Gun 時打不到 Anbaddin。原文記其生命力 5000。 |
| 3 | 敵人極少主動投降。**SAMAR 的 Kasuruji 是例外**。一般作法是打到敵人體力剩 **20～30** 時改按 **ENTER** 轉攻為守，多半會投降；若仍不降，改用 Turbo Gun 而不要用超能波。 |
| 4 | 不想打時按 **F3** 脫離，不一定成功，可重複按。 |
| 5 | 經驗值到一定程度會提升體力與超能力，也會增加超能力種類，例如 Shield 升級成 Mega Shield。 |

⚠ 第 2 條前半（第 28 頁右欄最上方三行）壓在深色太空船美術上，放大後仍只能讀出大意，
未逐字確認。中欄有淡色「PSYCHIC WAR」浮水印，但不影響判讀。

## 3. 主線流程

七個基地的造訪順序：SAMAR → SIVAD → ZELLWAL → RUSTECK → SAMAR → ZELLWAL → SIVAD → CELTAC → SHUA → CELTAC → RUSTECK → SIVAD → SAMAR → MELSER。

### 3.1 SAMAR（初訪，第 29 頁）

| 序 | 地點 | 動作 | 取得 |
|---|---|---|---|
| 1 | Bio Room (B) | 選 Healed | Yontry ×3 |
| 2 | Antiques (E) | 選 Sure，交出 3 瓶 Yontry | 地圖 PET |
| 3 | Repair (C) | 選 Advice | 情報：Koorak 解碼、Loran 顯示位置、Chia B 自動選圖 |
| 4 | Relic Shop (D) | 交談 | 情報：店主要地圖 Py |
| 5 | 出口 (G) | 搭載具 | 前往 SIVAD |

### 3.2 SIVAD（第 30 頁）

| 地點 | 動作 | 取得 |
|---|---|---|
| Safe (B) | Break it | 地圖 PO |
| VIP Room (C) | Search room | VIP Card |
| NRS Room (D) | 重複進出，每次 10 瓶 | Yontry ×60 |
| 出口 (E) | 搭載具 | 前往 ZELLWAL |

### 3.3 ZELLWAL（第 31 頁）

| 地點 | 動作 | 取得 |
|---|---|---|
| NRS Room (B) | 可重複拿，**總數上限 100 瓶** | Yontry |

| Lab (G) | — | Kayla 的 Loran |
| 出口 (E) | 搭載具 | 前往 RUSTECK |

### 3.4 RUSTECK（第 32 頁）

| 地點 | 動作 | 取得 |
|---|---|---|
| Safe C、D、E | — | 地圖 ADAK、RON、TATU |
| NRS Room (L) | 補到上限 100 | Yontry |
| Safe (I) | 用 VIP Card 開 | Turbo Gun |
| CPU Room (J) | 選 See device | Koorak |
| Armor (K) | — | 護甲 Ramzes（原文標防護力 6） |

離開 RUSTECK 前要找 **2 個 Dekto** 入隊，原因是後段旅程沒有 Mind-Jump 會走不下去。

### 3.5 SAMAR 二訪（第 33 頁）

1. Repair (C)：替 Kayla 裝上 Koorak 與 Loran。
2. 自行把 Gamera 能量匣裝到 Turbo Gun。
3. 找一名隊員用 Marker 記住 SAMAR 任一處。
4. 二度前往 ZELLWAL。

### 3.6 ZELLWAL 二訪（第 33 頁）

1. 選用地圖 LE，啟動 Kayla 的 Loran 與 Koorak。
2. H 處用裝了 Gamera 的 Turbo Gun 轟掉生化合成獸 Tatooman。
3. COM Room (I) 操作電腦，經 Kayla 解碼得密碼 **NOSHIRT!**。

原文附註：所有密碼都是 8 個大寫字母，**驚嘆號也算一個字元**。

### 3.7 SIVAD 二訪（第 33 頁）

1. 找一個 **PIONN**（有複製能力）入隊。
2. 用 NOSHIRT! 通過 Gate (F)。
3. 毀掉 DEF COM (I) 的 Defense Control。
4. Lab (K) 拿 Chia B。
5. Trap (L) 的 Houzz（有治療能力）可救可不救。
6. 回 SAMAR 替 Kayla 裝上 Chia B，之後才能前往 CELTAC。

### 3.8 CELTAC（第 34 頁）

生化合成獸在地圖上標號 **E**，Psycho Shield 標號 **D**。
原文說法：VIP Room (J) 附近與 6 號電梯附近那隻要用 Gamera，其餘多用 Rodan。

| 2 | K 處 | 用 VIP Card | 能量匣 Rodan |
| 3 | Gate (I) | 先用 Marker，再複製成任一怪物通過。Gate 檢查眼型，不複製過不了 | — |

### 3.9 SHUA（第 35 頁）

SHUA 沒有生化合成獸，但有 Psycho Shield（地圖上標 D）。

| 序 | 地點 | 動作 | 取得 |
|---|---|---|---|
| 1 | Stock Room (G) | — | 地圖 IRA |
| 2 | VIP Room (I) | — | SWEAT Crystal |
| 3 | Gate (J) | 經過時用 Marker 記位置 | — |
| 4 | Defense Control (E) | 開 Gate (J) 的鎖，再 Mind-Jump 到 Gate (J) | Psycho Gun |
| 5 | Bio Stock (C) | 同樣先 Marker，複製成 Zuutaim 後 Mind-Jump 回來 | ID Badge |
| 6 | Safe (B) | 轟掉 | E-Pack |

### 3.10 CELTAC 二訪與往 MELSER 的前置（第 35 頁）

1. Mind-Jump 經 SAMAR 到 CELTAC。
2. 複製成敵人後通過 Gate (Q)。**沒有 ID Badge 過不了。**
3. VIP Room (J) 拿 BLOOD Crystal。途中的生化合成獸要用 Gamera 殺。
4. Mind-Jump 回 SAMAR。
5. RUSTECK 的 CPU Room (J) 取得密碼 **NOSHOES!**。
6. SIVAD 的 Stock Room (J) 輸入 NOSHOES!，得地圖 Py。
7. 帶地圖 Py 與 E-Pack 回 SAMAR，把地圖 Py 給 Relic Shop 主人，即可借用傳送裝置傳到 MELSER。

### 3.11 MELSER 與結局（第 36 頁）

原文說 MELSER 的生化合成獸出沒不定，要看情況換能量匣，並善用 Teleport。

| 序 | 動作 |
|---|---|
| 1 | 毀掉 Shield Control (G) 的控制開關 |
| 2 | 毀掉 Shield Control (E) 的開關 |
| 3 | 依序用 TEARS、SWEAT、BLOOD 三顆 Crystal 啟動 Power Room **F、K、C** 內的自爆裝置 |
| 4 | CPU Room (I) 輸入密碼 **NODICE!!** 解碼 |
| 5 | Security (J) 輸入 System **E、D、C、E、D、C、A** 啟動自爆。失敗就離開再進來重試 |
| 6 | 逃命前到 Operate (H) 取 Beefun |
| 7 | 逃到 Hotel (L)，選 Leave 離開 |
| 8 | 用 Beefun 開啟 Launch Pad (M) 的門，選 **Go Home** 完成任務 |

⚠ **標號在不同張圖之間會衝突**：CELTAC 之一的圖例把 I 標成入口，但第 34 頁的 CELTAC 內文把 I 當成 Gate。

RUSTECK 的 J 是 CPU Room、MELSER 的 J 是 Security。**字母標號只在該張圖內有效。**

迷宮格線本身沒有轉錄。掃描解析度約 1060×1566，部分區塊的短牆與走廊分隔線分不清楚，
逐格重建會產生看起來自洽但錯誤的地圖。要用原版地圖資料的話，`I_MAP00–11.BIN` 是一手來源。

## 9. 這份攻略對專案的用處

1. **全程路線**。專案目前重播只到 Zellwal（`docs/re/013`、`019`）。這份攻略給出七個基地的完整順序、每一步要拿什麼、卡關點在哪，是把重播往後推的現成腳本。
2. **密碼與關鍵道具已經對上遊戲資料**。三組密碼、八張地圖、三種能量匣、三件護甲、三顆水晶都在 `text/` 裡找得到對應字串，可以直接拿來設計驗收路線。
3. **F2／F3 的衝突要處理**（§6.2 第一列）。這是目前看到唯一可能影響可玩性的問題。
4. **文章截圖不是 DOS 英文版**。要拿原版畫面對拍時不能用這十頁裡的截圖當參照。
