# 軟體世界代理版說明書（1989）整理

來源是《銀河超能力戰記》軟體世界代理版的紙本說明書掃描，19 張 JPEG（`Pic0001`–`Pic0019`），
出自骨灰集散地的「軟體世界說明書補完計劃」（掃描目錄內附 `軟體世界說明書補完計劃.txt`）。
**掃描圖不隨本專案散布**，已列入 `.gitignore`；本文只整理事實性資料（名詞、數值、操作、流程、表格），
不轉錄原書段落。故事與宣傳文案僅在必要處轉述一兩句並標明是原書說法。

本文的用途是當譯名與操作的權威來源：`text/glossary.json` 標「說明書」出處的條目在 §12 逐條核對。

## 4. 故事設定的事實項（p.1–p.3）

原書用三頁散文交代背景。以下只取可查證的設定項。

| 年（星際年曆） | 事件 |
|---|---|
| 3530 | 帝國軍侵入 KGD 星團；KGD 領導人遭控制。三個主要聯邦不屈服，第一次星際戰爭開始 |
| 約 3533 | 戰鬥持續三年半後聯邦全面潰敗 |
| 3652 | 帝國軍佔領 100 年後，KGD 星團脫離統治 |
| 3656 | 帝國成功發展出「超能波」，情勢再度告急；本作故事起點 |

其他設定項：

- 你的身分是聯邦上議院派出的超能戰士（Psychic Soldier）。
- 凱拉（Kayla）是解救 KGD 星團之戰中的生化複合人，本作中以女郎身份同行。
- 帝國方面的星系叫奎拉（Quila）。
- 任務目標是趕在帝國發動總攻擊前摧毀其衛星系統。
- 故事起點在帝國星系外環一個中立的貿易站，即薩瑪（SAMAR）。
- p.3 的遊戲畫面翻拍裡出現太空戰艦名 `CENTURY PARODY`（原書中文正文未譯出此名）。

## 5. 系統需求與安裝（p.3–p.5）

| 項目 | 內容 |
|---|---|
| 主機 | IBM PC XT／AT 或 100% 相容機型，主記憶體至少 384K |
| 磁碟機 | 一台 |
| 顯示卡 | 單色（MGA）或彩色（CGA、EGA） |
| 作業系統 | DOS 2.1 以上 |
| 搖桿 | 非必備 |
| 音效卡 | 魔奇音效卡（AdLib），非必備 |
| 空白磁片 | 一片已格式化磁片，軟碟玩家用來存進度；硬碟玩家不需要 |

安裝到硬碟：建 `PW` 子目錄，把 Disk 1、Disk 2 的檔案都 `COPY` 進去。
啟動：軟碟放 Disk 1 後在 `A>` 鍵入 `PW`；硬碟進 `PW` 目錄後鍵入 `PW`。

啟動參數（p.6）：

| 指令 | 作用 |
|---|---|
| `PW H` | 單色 HGA |
| `PW C` | 4 色 CGA |
| `PW E` | 16 色 EGA |
| `PW T` | 16 色 Tandy 1000 |
| `PW J` | 使用搖桿 |
| `PW S` | 關閉音樂 |

不加參數時程式自動偵測輸出設備並選最佳顯示方式。

## 6. 開場流程（p.6–p.10）

1. 出品公司畫面。
2. 主題音樂配插圖，出現故事大綱（原書提到有魔奇音效卡時是鐘琴音色）。按任一鍵跳到密碼畫面。
3. 密碼畫面：畫面給「戰友姓名 ↔ 衛星基地」，查密碼表找出對應的超能力名稱鍵入。複合字中間要加連字號。
   答錯要重來；原書寫「凱拉只給你二次機會」，第三次要重新啟動遊戲。
4. 進度選單 `Select`：`NEW GAME` 或 `LOAD GAME`，用 ↑↓ 選、ENTER 進入。
   `LOAD GAME` 在軟碟模式會要求插入 USER DISK，然後 `INPUT FILE NAME :`。
5. `NEW GAME` 會出現 `ENTER YOUR NAME :`。輸入姓名後，你和凱拉已進入薩瑪（SAMAR）交易站。

### 7.2 F1／F2／F3（原版自己的功能鍵）

這一節是 issue #42 的直接證據：說明書明寫三個鍵各自做什麼。

| 鍵 | 說明書原文的作用 | 條件 |

## 8. 畫面區塊與狀態欄位（p.11–p.13）

### 8.1 主遊戲畫面的九個區塊

| 區塊 | 說明 |
|---|---|
| 全隊資料區 | 小組成員資料、地圖及其他物品名稱 |
| 物品顯示區 | 遊戲中尋獲的戰鬥物品 |
| 指令區 | 選單畫面所在，決定小組行動 |
| 凱拉戰士 | 凱拉的立繪。要在薩瑪的修復站（Repair Room）幫她裝上特殊裝備才能發揮戰力 |
| 訊息區 | 遊戲訊息；需要輸入口令（Password）時也在此輸入 |
| 次訊息區 | 目前位置（`PLACE`）和方位（`DIRECTION`） |
| 3-D 立體畫面 | 遊戲情節所在 |
| 戰鬥區 | 你和小組成員；小組最多可有 3 位其他成員。戰鬥也在此發生 |
| 能量指數 | 每位成員下方的目前體力指數 |

### 8.2 全隊資料區的欄位

| 畫面標籤 | 意義 |
|---|---|
| `NAME` | 隊友姓名 |
| `POW` | 目前體力指數 |
| `max`（POW 下一行） | 最大體力指數 |
| `ESP` | 目前超能力指數 |
| `max`（ESP 下一行） | 最大超能力指數 |
| `ARM` | 護甲 |
| `LEV` | 等級 |
| `EX` | 經驗指數 |
| 下方列表 | 該成員擁有的超能力 |

規則：

- 經驗累積到一定值時等級提高一級，經驗歸 0 重新累積，同時體力與經驗上限提高。
- 凱拉的超能力指數 ＝ 每位成員目前超能力指數的總和。
- 戰鬥時最前線戰士體力降到 0 就損失該成員，依此類推，直到打贏或全隊被消滅。
- 凱拉的能量指數降到 0 表示全隊超能力指數為 0，失去攻擊與防護能力。

## 9. 主功能選單（p.13–p.16）

`ESC` 打開。用 ↑↓ 移動箭頭、ENTER 執行，選 `Cancel` 脫離選單。
項目前有 `*` 者表示找到該物品之後選單上才會出現。

| 選項 | 說明書譯法 | 內容 |
|---|---|---|
| `Ask Kayla` | 詢問凱拉 | 凱拉重獲感應器（`Sensor`）、選圖器（`Mapper`）、解碼器之後，出現這三種副選項；選了凱拉會說明她已啟動或關閉該裝備 |
| `*Sip Yontry` | 喝體力恢復劑 | 取得 `Yontry` 藥劑後可用。出現四位戰士姓名副選單，選一位恢復其體力 |
| `*See Maps` | 顯示地圖 | 地圖在衛星站各處的保險箱（`Safe`）裡。配合凱拉的感應器可知道自己的位置。副選項 `Negative` 跳過目前地圖看下一張，`Totally` 選定本張在資料區顯示並脫離選單 |
| `*Turbogun` | 強力加速砲 | 出現三種能量匣選項，選一項裝上加速砲，完成待命射擊狀態 |
| `ESP Power` | 使用超能力 | 出現**四種**超能力選單，選定後再出現四位成員姓名選單，要選擁有該能力的戰士 |
| `OPTIONS` | 功能選項 | 底下有 `Save Game`、`Sound` |
| `Save Game` | 儲存遊戲 | 先選 `Definitely`（確定）或 `No Way`（跳離）。軟碟玩家要放入格式化過的磁片。檔名 8 個以內文數字、中間不可空白，以 `<檔名>.DAT` 儲存。要覆蓋同檔名時在輸入檔名畫面按 ↓ 找到該檔名。存完選 `Absolutely` 繼續遊戲或 `No Way` 跳離遊戲 |
| `Sound` | 音效 | `Yes` 打開、`No` 關閉 |

### 13.4 衝突與要注意的地方

1. **`Psycho Shield` 撞名**。說明書 p.20 把 `PSYCHOBARRIERS` 定譯「能量障壁」；
   而 `text/I_MENU09/10/11` 裡的 `Psycho Shield`／`Psycho {C2}{D2}{E2}{F2}` 目前譯成「超能防護盾」，
   與 ESP 的 `Shield`「防護盾」、`Mega Shield`「超強防護盾」撞在一起。
   同一批訊息旁邊就是 `PsychoOFF is in the basement.`（超能控制室），與 p.20
   「先毀掉所有的超能控制室才能除去能量障壁」講的是同一件事。**建議統一成「能量障壁」。**
2. **「瞬間移位」一詞在說明書裡指兩個東西**：ESP 的 `Teleport`（p.17，逃離戰鬥現場）
   和 `F3` 鍵（p.8，向後移動一步脫離戰鬥）。原書自己就這樣寫。
   中文說明頁若要寫 `F3`，需要另外措辭以免混淆。
3. **密碼表的 11 個名字在 glossary 裡 `kind` 標成 `enemy`**。密碼表稱他們「戰友」，
   p.17 說在薩瑪可以用 `F2` 選 `Team up` 讓他們加入。兩種身分都成立（投降的敵人會加入），
   但只標 `enemy` 會誤導。建議加註或改成 `ally`。
4. **封底的「8 種超能戰士」與密碼表的 11 個名字對不上**，也與 `text/` 抽出的敵人名數量對不上。
   宣傳數字不可當依據。
