# M2：可遊玩前端

## 目標

**原版英文遊戲可以在視窗裡以原速、有聲音地玩，操作手感與原機相近。**
M2 做完時還沒有中文，但「golem 當執行器給人玩」這件事已經成立。

## 完成定義

| 項目 | 驗收 | issue |
|---|---|---|
| 牆上時間節拍 | spec 定案每 tick 指令數的依據；執行時計時器中斷穩定在 72 Hz ±1%；CPU 用量有數字 | #9 |
| 視窗 | `cmd/psychicwar` 開視窗顯示標題畫面，顏色正確，nearest 整數倍放大；Linux 可在 docker 建置 | #10 |
| 鍵盤 | 完成防拷、輸入名字、移動、選單；F1／F2／F3／F10 被前端攔下，不送進遊戲 | #11 |
| 滑鼠 | 原版滑鼠支援的結論進 `docs/re/`；前端可以用滑鼠點選單項目與方向 | #12 |
| 音訊 | 遊玩時聽得到音樂，沒有明顯斷音或速度偏差；可切換 AdLib／PC 喇叭 | #13 |
| 輸入錄放 | 錄一段遊玩後重播，終點畫面與記憶體逐位元組相同 | #14 |

## 量測指標

- 計時器中斷頻率：72 Hz ±1%。
- 錄放重現：終點記憶體差異 **0 bytes**。
- 前端框架（預設 Go／Ebiten）與支援平台寫進 spec。

## 歸屬

節拍（#9）與輸入錄放（#14）是通用機制，送 dosgolem；視窗、按鍵對應、音訊輸出先放本 repo，穩定後再評估抽回。
