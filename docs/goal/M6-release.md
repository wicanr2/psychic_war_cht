# M6：主題、打包、授權與發行

## 目標

**玩家在 Linux、Windows、macOS 上解開發行包、指定自己的原版目錄，就能玩中文版。**
同時把「換主題」做成資料檔，作為轉譯層可以延伸的例子。

## 完成定義

| 項目 | 驗收 | issue |
|---|---|---|
| 主題替換 | 主題是資料檔；原版畫面是預設主題；切換後四個檢查點畫面正常、遊戲狀態不變 | #34 |
| 跨平台打包 | 依 `rulebook/82`：三個平台各自從乾淨環境解開、指定原版目錄、玩到主畫面；驗證紀錄進 `docs/` | #35 |
| 授權與 README | RRSAL-1.0 全文進 `LICENSE`，第 2 條 (c) 點名本專案的灰色地帶；README 寫明玩家要自備的版本與 SHA-256 | #36 |

## 量測指標

- 發行包內的原版素材檔數：**0**（打包腳本檢查）。
- 三個平台乾淨環境的啟動驗證：**3／3 通過**。

## 設計約束

- 發行包不含原版素材，啟動時驗證玩家檔案的 SHA-256，不符時說明需要哪個版本。
- 授權依 `rulebook/85`（RRSAL-1.0，已定案）。
