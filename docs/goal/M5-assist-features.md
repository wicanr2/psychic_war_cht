# M5：輔助功能

## 目標

**提供原版沒有、但因為遊戲跑在 golem 上才做得到的功能，而且不修改任何原版檔案。**
這一期要證明「轉譯層」不只是換字：能讀寫記憶體、存取整台機器的狀態，就能加上 remake 才有的體驗。

## 完成定義

| 項目 | 驗收 | issue |
|---|---|---|
| 防拷 | 判定常式進 `docs/re/`；三種用法各有測試：照說明書作答、F1 查表、設定中略過 | #28 |
| F1 說明 | 任何畫面都能開關；開關前後遊戲記憶體相同 | #29 |
| F2 切換語言 | 任一畫面切換中文／英文原文，文字立即改變，遊戲狀態不變 | #30 |
| F10 即時存檔 | 存檔後重開程式讀回，畫面與記憶體相同；golem 版本或原版 SHA-256 不符時拒絕並說明原因 | #31 |
| F3 地圖 | 地圖資料來源（`I_MAP*`／`MAZE.BIN` 格式或記憶體位址）進 `docs/re/`；顯示目前區域與玩家位置、朝向，與實際移動一致 | #32 |
| 作弊 | 角色狀態位址表有讀寫點證據；至少提供回復 HP／ESP 與防拷略過；開啟時畫面有標示 | #33 |

## 量測指標

- 輔助功能開關前後的遊戲記憶體差異：**0 bytes**（作弊功能除外）。
- 即時存檔讀回後的記憶體差異：**0 bytes**。

## 設計約束

- 一律透過 golem 讀寫記憶體，不改原版檔案。
- 防拷的查表與略過依 `~/.claude/knowledge-base/retro/ida-pro-9.4.md` 的老遊戲保存例外：
  在執行層攔判定、不散布改過的執行檔、原版作答流程保留，略過只是額外選項。
- 位址表放 `apps/psychicwar`，每個位址附證據等級。
- 熱鍵分派、存檔落地是通用機制，送 dosgolem；說明內容、地圖解讀、作弊位址留本 repo。
