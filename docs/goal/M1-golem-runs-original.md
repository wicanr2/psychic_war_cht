# M1：原版在 golem 上完整可跑

## 目標

**原版在 dosgolem 上從開頭跑到結局，畫面、顏色、音樂都與原版一致，而且同一組輸入永遠得到同一個結果。**
這是轉譯層的地基：底下的機器錯了，上面疊的中文再漂亮也是錯的。

## 完成定義

| 項目 | 驗收 | issue |
|---|---|---|
| EGA 色盤 | mode 0Dh 的色號經屬性控制器對到 EGA 64 色；四個檢查點的 RGB 與 DOSBox-X 參照一致；dosgolem 端有測試 | #4 |
| OPL2 合成 | `.MID` 路徑的標題音樂可合成成 WAV，音高與節奏與 DOSBox-X 錄音一致 | #5 |
| PC 喇叭 | `.IBM` 格式寫進 `docs/re/`；標題音樂 WAV 與 DOSBox-X 錄音一致 | #6 |
| 決定性 | 亂數常式與種子來源寫進 `docs/re/`；同一組輸入跑兩次，戰鬥結果逐項相同 | #7 |
| 全程可跑 | 一份可重播的全程輸入（或檢查點串）跑到結局，未實作服務為空，結局畫面存證 | #8 |

## 量測指標

- 四個檢查點與 DOSBox-X 的 RGB 不一致像素數：**0**。
- 全程重播中的未實作服務數：**0**。
- 同一輸入兩次執行的記憶體差異：**0 bytes**。

## 歸屬

#4、#5 是 dosgolem 的機器層缺口，在 `worktrees/dosgolem` 開分支修，推上游前先回報。
