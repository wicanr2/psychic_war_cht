# 第 9 輪：AdLib 合成器、輸入、授權

## 目標

**讓中文版有聲音、有完整的輸入（鍵盤與滑鼠、可錄可放），並把授權放進 repo。**

第 8 輪之後畫面上的文字都是中文了，剩下的體驗缺口是**聽得到**與**操作完整**。
本輪的主軸是 AdLib 合成器：暫存器序列早就與 DOSBox-X 逐筆相同（5,599 筆），
但沒有合成器把它變成聲音，所以 AdLib 路徑目前是啞的。

  已移到 `docs/worklist.json` 的 `dropped`。

- **授權採 RRSAL-1.0**，本輪放進 `LICENSE`。

## 本輪完成條件

1. **OPL2 合成器（#5）——本輪第一順位**
   - **先把判準寫成規格**：`docs/re/007` 用的方法（`tools/music_compare.py opl`）分辨力不足，
     做完也無法宣稱成功。事件層已經與 DOSBox-X 逐筆相同，所以要驗的是**合成器本身**：
     建議拿單一 operator、已知包絡與頻率的樣本對波形，再回到整曲的音高／節奏比對。
     判準定不下來就寫明改用什麼，不要做完才發現沒有驗收方法。
   - 實作放 dosgolem（`internal/machine` 或新套件，spec 先寫 READY）——換一款遊戲仍然成立。
   - 驗收：標題曲與迷宮曲各一段，與 DOSBox-X 錄音的音高、節奏比對通過；
     逐樣本對不上時要寫明差在哪（相位、包絡斜率、取樣率換算）。
2. **即時音訊輸出（#13）**
   - 目前只在 `-audio null` 驗過。要在真實音效卡或 dummy sink 上量。
   - 驗收：60 秒 AdLib 欠載 0（開場第 1 秒除外）、PC 喇叭同樣；**量測條件**每核負載 < 0.5
     （這台 14 核 ＝ load < 7）。第 8 輪在每核 0.36 時量到第 2–65 秒 0，這個門檻夠用。
3. **輸入名字（#26）**
   - 只支援 ASCII（定案）。提示文字與周邊訊息中文化；輸入框沿用原版的格子。
   - 驗收：輸入、存檔、讀檔、狀態頁四處顯示一致；存檔檔名在 DOS 檔案系統上合法；
     非 ASCII 輸入要被擋掉並且看得出來被擋（不是靜默丟棄）。
4. **滑鼠（#12）**
   - 先確認**原版是否支援滑鼠**（`docs/re/002` 的 `INT 33h` 呼叫點表是起點）。
     原版不支援的話，前端自己把點選映射成按鍵——這是轉譯層的功能，不是模擬原版。
   - 驗收：操作面板的四個項目（前進、轉向、向後轉、選單）可點選；點選與按鍵走到同一個狀態
     （同一起點、同一操作，記憶體逐位元組相同）。
5. **輸入錄放（#14）**
   - 以指令數記錄按鍵，可重播重現（dosgolem 規格，spec 先寫 READY）。
   - 驗收：錄一段包含戰鬥的操作，重播後逐位元組相同；錄影檔換一台機器仍能重現（決定性靠指令數，不是牆上時間）。
   - 這一項做完，抽測試玩與回歸測試都可以用錄下來的操作，不必每次靠 xdotool 重打。
6. **LICENSE（#36 的一部分）**
   - 放入 RRSAL-1.0 全文（範本 `~/.claude/knowledge-base/retro/rrsal-1.0.md`）。
   - README 要寫明：字型來源是倚天中文系統 3.53 的點陣子集與下架聯絡方式；原版素材不散布，玩家自備。
   - `#36` 的 README 改寫可以留到發行那一輪，本輪只要 `LICENSE` 與字型來源聲明。
7. `tools/py.sh tools/worklist.py verify` 沒有「可能已完成」；做完的條目移到 `done`；本機 commit。
