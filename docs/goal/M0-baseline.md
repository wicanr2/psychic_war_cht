# M0：探勘與基線

## 目標

之後每一期都要靠三樣東西：**讀得懂的執行檔**、**快速到達指定畫面的檢查點**、**可以比對的正確答案**。
M0 就是把這三樣建好，讓後面的實驗是秒級、有依據的。

## 完成定義

| 項目 | 驗收 | issue |
|---|---|---|
| IDA 函式普查 | `PW.EXE`／`LOGO.EXE` 的 `.i64` 建好；函式總數、runtime helper 數、已執行數、真正的 `INT` 呼叫點列表進 `docs/re/`，附輸入 SHA-256 | #1 |
| 狀態檔檢查點 | `tools/states.sh` 一次產出四個檢查點：標題、防拷、輸入名字、第一個可操作畫面；每個附解幀畫面與到達指令數 | #2 |
| DOSBox-X 參照 | 同四個檢查點在 DOSBox-X 的色號陣列＋色盤；與 dosgolem 逐像素比對的結果進 `docs/re/` | #3 |

## 量測指標

- 從檢查點載入到可以下一步實驗的時間（目標：秒級）。
- dosgolem 與 DOSBox-X 在四個檢查點的**色號**不一致像素數（目標：0；顏色差異屬於 M1 #4）。

## 不在範圍內

- 修 dosgolem 的任何缺口（M1）。
- 解文字或圖檔格式（M3）。

## 起點

`PW.EXE` 已能跑到主畫面，顯示模式 0Dh、音樂兩條路徑（`.IBM`／`.MID`）都已確認，見 `docs/re/001`。
