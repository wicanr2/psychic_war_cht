# M4：中文繪製與全文翻譯

## 目標

**正常玩家從開頭玩到結局，看到的文字全部是中文，沒有漏譯、沒有破版、沒有英文殘影。**

## 完成定義

| 項目 | 驗收 | issue |
|---|---|---|
| 放大畫布＋疊字層 | spec READY；一則訊息在放大畫布上以中文顯示，底圖與原版一致、沒有英文殘影 | #20 |
| CJK 點陣字 | 烘製走 docker；譯文用字 100% 有字模，缺字時建置失敗；字型授權允許再散布 | #21 |
| 排版規則 | 固定寬度框的容字量、換行、超長處理規格 READY；超出版面的譯文在建置時列出 | #22 |
| 譯名表 | `text/glossary.json` 涵蓋所有專有名詞，每筆標出處（說明書頁碼或自訂） | #23 |
| 全文翻譯 | 譯文欄全部非空；譯名檢查與排版檢查通過 | #24 |
| 圖檔文字替換 | 清冊每一項都有中文替換圖；四個檢查點畫面沒有英文圖字 | #25 |
| 輸入名字 | 中文版的名字處理方式寫進 spec；存讀檔後名字顯示正確 | #26 |
| 中文版試玩 | 正常玩家路徑含存讀檔走到結局，試玩紀錄進 `docs/` | #27 |

## 量測指標

- 譯文為空的筆數：**0**。
- 缺字模的字數：**0**。
- 超出版面的譯文：**0**。
- 全程重播中「觸發了卻不在文本檔」：**0**（M3 #19）。
- 四個檢查點與全程試玩中的英文殘影：**0**。

## 設計約束

- 依 `rulebook/81`：放大畫布，不把中文縮進 8×8 字格。
- 人名、地名、超能力名稱優先沿用軟體世界代理版說明書的譯名。
- 英文版是主要原文，PC-88 日文版用來確認原意。
