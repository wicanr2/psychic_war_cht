# 003：狀態檔檢查點與 DOSBox-X 參照畫面

狀態：量測紀錄（2026-09-17）。對應 issue #2、#3。

## 1. 結論

- `tools/states.sh` 從開機產出七段狀態檔，其中四個是 M0 檢查點；全程 **19 秒**。
  同一份腳本跑兩次，七格畫面的雜湊都相同（`--check`）；竄改一格期望值時會報失敗。
- DOSBox-X 以獨立實作走到同樣四個畫面，與 dosgolem 逐像素比對：
  **標題、輸入名字、第一個可操作畫面都是 0 個不一致像素**；防拷畫面不一致 128 像素，全部落在盟友名稱那一列，原因是兩邊的亂數不同。
- 比對得出每個色號在 DOSBox-X 的實際顏色。**色號 8 在遊戲裡是黑色**，EGA 預設是深灰：遊戲確實改過色盤，
  而 dosgolem 目前的輸出沒有反映這一點（issue #4）。

### 2.1 畫面停留行為

不送按鍵時，畫面從第 9,000,000 步起不再變化，一直到 60,000,000 步：標題會停下來等按鍵。
`05-select` 與 `07-first-play` 有週期性變化（選單游標、迷宮畫面的閃爍），週期分別約 2,600 萬步與 800 萬到 1,000 萬步。

### 2.2 與防拷有關的觀察

- 問哪一位盟友會隨按鍵的指令數改變：同一段流程在不同時機按鍵，問題不同
  （本輪 dosgolem 是一組名稱，docs/re/001 那一輪是另一組，DOSBox-X 又是另一組）。亂數來源由 issue #7 追。
- 在 `ENTER ESP POWER` 直接按 enter（空白答案），dosgolem 顯示 `YOU ARE CLEARED`。
  DOSBox-X 以同樣操作也走到了主畫面，兩個實作行為一致。判定邏輯還沒讀（issue #28）。

## 3. DOSBox-X 參照

### 3.1 設定

`tools/dosboxx-ref.sh`，image `civ1-dosboxx-input:20260830`（DOSBox-X 2026.06.02 SDL1）。

| 項目 | 值 | 理由 |
|---|---|---|
| `machine` | `svga_s3` | 遊戲以 `INT 10h AH=12h` 查 EGA，VGA 相容卡可通過 |
| `cputype`／`cycles` | `286`／`fixed 8000` | 固定週期，不用 `auto` |
| `sbtype`／`oplmode` | `none`／`none` | 與 dosgolem 預設的「沒有 AdLib」同一條音樂路徑 |
| `scaler`／`aspect` | `none`／`false` | 視窗 640×400，整數 2 倍 |

擷取用 X 視窗截圖（`import`）轉 raw RGB。這個版本在此設定下按 Ctrl+F5 不產生截圖檔，所以沒有索引色 PNG。
因此 DOSBox-X 端的參照是 **RGB 畫面**；色號陣列與色盤由比對工具從 RGB 導出。

### 3.2 比對方法

`tools/frame_compare.py`：

1. 驗 DOSBox-X 畫面每個 2×2 區塊同色（四個檢查點全部 0 個例外），再縮回 320×200。
2. 對每個 dosgolem 色號，取它在 DOSBox-X 最常對到的 RGB 當對應；與對應不符的像素算不一致。
3. 檢查對應是否一對一。

比對的是**版面**：dosgolem 輸出的色號還沒經過遊戲色盤，所以不直接比 RGB。
標題與迷宮畫面各抓多張（標題 6 張、迷宮 3 張），全部候選都是 0 不一致。

### 3.3 結果

| 檢查點 | 不一致像素 | 不一致範圍 | 用到的色號 |
|---|---:|---|---:|
| `01-title` | 0 | — | 6 |
| `03-protection` | 128 | x 118–200、y 89–93（盟友名稱那一列） | 2 |
| `06-name` | 0 | — | 13 |
| `07-first-play` | 0 | — | 14 |

### 3.4 色號與顏色（issue #4 的參照）

四個檢查點合併的對應（DOSBox-X 實際顯示的 RGB）：

| 色號 | RGB | 與 EGA 預設 |
|---|---|---|
| `0` | `000000` | 相同 |
| `1` | `0000AA` | 相同 |
| `3` | `00AAAA` | 相同 |
| `4` | `AA0000` | 相同 |
| `5` | `AA00AA` | 相同 |
| `6` | `AA5500` | 相同 |
| `7` | `AAAAAA` | 相同 |
| `8` | `000000` | **不同**（預設 `555555`） |
| `9` | `5555FF` | 相同 |
| `B` | `55FFFF` | 相同 |
| `C` | `FF5555` | 相同 |
| `D` | `FF55FF` | 相同 |
| `E` | `FFFF55` | 相同 |
| `F` | `FFFFFF` | 相同 |

色號 `2`、`A` 在這四個畫面沒有出現，沒有參照。
色號 `8` 只在 `07-first-play` 出現 25 個像素（x 160–166、y 77–83，迷宮視角中央），證據量小；
更多畫面的參照要等 issue #4 修色盤時補。

## 4. 限制與重開條件

- 防拷畫面的 128 像素差異來自亂數；要逐像素相同，需要先解 issue #7，讓兩邊的亂數對齊。
- DOSBox-X 端沒有索引色擷取；若之後需要區分「兩個色號被設成同色」，改用 DOSBox-X 除錯器讀屬性控制器暫存器。
- 狀態檔綁 dosgolem `d9c0c27`。換版本要重跑 `tools/states.sh --check`。
