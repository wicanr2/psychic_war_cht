# 030：F3 自動地圖

狀態：量測紀錄（2026-09-18）。對應 issue #32。規格 `docs/spec/015`；座標來源 `docs/re/011`。

## 1. 結論

**不解地圖檔**（`I_MAP` 的牆壁位元至今沒解），改成走過才記：前端每一幀讀腳本變數
（區域 `0x16966`、X `0x16968`、Y `0x1696A`、朝向 `0x16970`），把走過的格子記起來，F3 開關顯示。

| 驗收（`docs/spec/015` §4） | 結果 |
|---|---|
| 單元測試（合理範圍、去重、分區域、JSON 往返、朝向記號） | 通過 |
| 實跑：從 `07-first-play` 往前走 3 步再按 F3 | 目前格子 (1, 11) 是白色，與存檔裡的座標相同 |
| 走過的格子 | 3 個（不含目前格）全部是灰色 |
| 反向對照：沒走過的格子 | 抽驗 5 個，全部是黑色 |
| 開關 F3 前後的觀測變數（`lin:16966` 起 52 bytes） | 相同 |

期望值不是前端自己說的：格子顏色比對用的座標來自**即時存檔**（probe 從狀態檔讀），
走過的格子來自前端存下來的 `quick.map.json`。

## 2. 走過的坑（寫成規則）

- **畫面上要出現的中文，來源一律放進 `text/` 的資料檔**，否則字型子集收不到，畫出來是缺字。
  這一輪踩了三次：`text/baked.json` 的譯文（schema 不同沒被收）、F1 的「本題答案：」標籤、
  自動地圖的「區域…座標…」標題。現在 `help.json` 裡除了 `lines` 之外的字串欄位也會被烘字腳本收走。
  規則：**新增任何「寫死在程式裡的中文」之前，先問它從哪個資料檔來。**
- 地圖資料跟著 F10 即時存檔存成 `quick.map.json`；格式不對就當空的，**不讓地圖壞掉害讀檔失敗**。
