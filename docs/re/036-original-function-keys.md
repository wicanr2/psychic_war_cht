# 036：F1、F2、F3 是原版的功能鍵

狀態：量測紀錄（2026-09-19）。對應 issue #42。規格 `docs/spec/012`、`014`、`015`。

## 1. 結論

**F1、F2、F3 是原版自己的功能鍵，前端不可以拿去做輔助功能。**
輔助熱鍵改從 F4 起算，F9 也留給原版。

| 項目 | 結果 |
|---|---|
| 語意來源 | 軟體世界代理版說明書 p.8、p.17（`docs/manual-1989.md`）|
| 端到端驗證 | 遭遇戰中按 F3，畫面回到迷宮、方向由北變南（向後一步）|
| 對照組 | 同一個狀態檔不按鍵，畫面只變 657 像素（游標閃爍）|
| 兩次執行的起點 | 逐像素**差 0**，所以變化只能來自那一次按鍵 |

## 2. 原版用哪些鍵（說明書 p.8）

| 鍵 | 功能 |
|---|---|
| F1 | 發射強力加速砲（Turbogun）。**要先裝能量匣** |
| F2 | 和其他戰友或投降的敵人交談。p.17：在薩瑪可以 `Team up` 招募或 `talk` 取情報 |
| F3 | 瞬間移位，向後移動一步以脫離戰鬥現場。原書註明「不是每次都有效」 |
| Enter | 使用防護盾 |
| Esc | 主選單 |
| Ctrl+R／Ctrl+J／Ctrl+Q | 不存檔重選進度／切搖桿／回 DOS |

說明書沒有提到 F9。

## 3. 原本錯在哪

兩層，而且第二層讓第一層的症狀變成「什麼都沒發生」：

1. `intercepted` 把 F1／F2／F3 攔下來，指派給說明頁、中英切換、自動地圖。
2. `scanCodes` **只涵蓋 F4–F9**（`0x3E`–`0x43`）。F1／F2／F3 連掃描碼都沒有。

所以就算把第 1 層拿掉，那三個鍵**仍然送不進遊戲**。
玩家看到的是「按了沒反應」，不是錯誤訊息——沒有任何內部訊號會亮。
`docs/re/025` 的熱鍵驗收也抓不到，因為它驗的是「我們的功能有沒有生效」，
不是「原版的功能有沒有被擋掉」。

**規則：攔一個鍵之前，先確認原版有沒有在用它。**
「這個鍵目前沒有指派」不等於「原版沒用」——沒有掃描碼的鍵，原版永遠收不到，
也就永遠看不出它其實會用。

## 4. 驗證方法

端到端的對照實驗，不看內部訊號（`rulebook/65`）：

1. 同一個狀態檔（`08-encounter`，遭遇戰中）起兩次前端。
2. 一次在同樣的時點按 F3，另一次什麼都不按。
3. 比四張截圖。

```
起點相同嗎（兩次執行的 before）：0
按了 F3：before vs after        27438
沒按：  before vs after           657
按 F3 vs 沒按（after 比 after）： 27429
```

兩次執行的起點逐像素差 0，所以 27,438 的變化只能來自那一次按鍵。
按鍵後的畫面是迷宮，操作面板回來了，狀態欄的方向由北變南——
與說明書寫的「向後移動一步以脫離戰鬥現場」相符。

⚠ 按鍵要**按住 0.15 秒以上**（`xdotool keydown` ／ `sleep` ／ `keyup`）。
按下與放開落在同一個 1/60 秒的輪詢裡，Ebiten 會整個漏掉（`docs/re/016`）。

## 5. 現在的分配

| 鍵 | 給誰 |
|---|---|
| F1、F2、F3、F9 | **原版** |
| F4 | 說明頁 |
| F5 | 中文／英文切換 |
| F6 | 自動地圖 |
| F7、F8 | 作弊（要 `-cheat`）|
| F10、F11 | 即時存檔／讀檔 |

單元測試分成兩組斷言（`apps/psychicwar/frontend_test.go`）：
輔助鍵要被攔；原版的鍵**不可以攔，而且要有掃描碼**。
少了後半句，這個 bug 會原樣復活。

## 6. 沒驗到的

- F1 與 F2 沒有端到端驗過。F1 要先裝能量匣、F2 要有戰友或投降的敵人在場，
  兩個前提在 `08-encounter` 都不成立。掃描碼有沒有送出去由單元測試涵蓋。
- F4–F8 會不會撞到原版的其他功能，沒有查。說明書沒提到這些鍵，
  但說明書不一定寫全。真正要確認得讀原版的 `INT 09h` 處理常式。
- 靜態掃立即數**找不到**功能鍵的掃描碼比較（`3Bh`／`3Ch`／`3Dh` 在反組譯裡
  分別是計數器上限 60、位元組碼直譯器的 opcode 範圍、大寫字母分類），
  所以原版應該是查表分派而不是逐一 `cmp`。
