## 2. 操作（說明書摘要）

說明書第 7–8、15–16 頁（`175-銀河超能力戰記.rar`，軟體世界版）：

| 操作 | 按鍵 |
|---|---|
| 前進／左轉／右轉／向後轉 | 數字鍵盤 8／4／6／2 |
| 發射超能波（攻擊） | 空白鍵 |
| 防護盾（還有防護能力時） | Enter |
| 強力加速砲（需裝能量匣） | F1 |
| 與戰友或投降的敵人交談 | F2 |
| 瞬間移位：向後一步脫離戰鬥（不一定成功） | F3 |
| 主功能選單 | Esc |
| 存檔 | Esc → Options → Save Game → Definitely → 輸入檔名（8 字內英數） → Absolutely |
| 讀檔 | 開頭進度選單 → LOAD GAME → 輸入檔名 |

實測選單順序：主功能選單是 Ask Kayla／See Items／ESP Power／Options／Cancel；Options 底下是 Save Game／Sound／Cancel。
硬碟版不會出現換磁片的提示，說明書軟碟版的那一步要省略（多按一次 Enter 會送出空白檔名，存成 `.DAT`）。

## 3. 第一場戰鬥

遭遇：從迷宮起點往前 11 步，敵人 Shulosu（左側數值 38），玩家 40。遭遇位置固定，與亂數無關（docs/re/004）。

| 打法（從 `08-encounter` 開始） | 次數 | 結果 |
|---|---:|---|
| 空白鍵 16 次、每 100 萬步一個事件，第一鍵時機掃 30 種（每 5 萬步） | 30 | 全部陣亡，回到輸入名字 |
| 空白鍵 12 次、每 120 萬步 | 1 | 陣亡（第 1 億步時敵 15、我 6） |
| 空白鍵 150 次、每 20 萬步 | 1 | 陣亡（第 9,800 萬步時敵 13、我 5） |
| 空白鍵與 Enter（防護盾）交替 | 1 | 陣亡；之後佇列裡剩下的 Enter 讓輸入名字直接開了新局 |
| 先 Enter 再連按空白鍵 | 1 | 陣亡 |
| **F3 瞬間移位** | 1 | **脫離戰鬥**，HP 40，朝向變成 South |

連按空白鍵確實會持續攻擊，敵人數值一直下降，但玩家先倒下。攻擊時右上角的另一個數值（30→27→22）也在下降，推定是攻擊消耗的能量（假說）。
**怎麼打贏還不知道**：可能要用防護盾抓時機、ESP Power、加速砲，或先提升角色。

⚠ probe 的 `-press` 是「按下＋放開」兩個事件、每個事件間隔 `-press-every`，佇列會節流：150 次按鍵排得太密時，
戰鬥結束時佇列裡還剩 107 個事件。**「按住不放」目前無法表達**，要在 dosgolem 補送原始掃描碼的方式。
