# 014：作弊（補血、補能量、削弱敵人）

狀態：**READY**
日期：2026-09-18
對應：issue #33
前置：位址 `docs/re/011`（腳本變數）、`docs/re/009` §3（敵人 HP）；熱鍵 `docs/spec/012`

## 1. 原則

- **一律寫記憶體，不改原版檔案**（CLAUDE.md 的硬規則）。位址表是遊戲專屬的，放 `apps/psychicwar`。
- 預設**關閉**：要 `-cheat` 才會生效，避免不小心按到毀了正常遊玩的紀錄。
- 只做「讓卡關的人過得去」的三件事，不做無敵或跳關。

## 2. 位址（段 0161 的線性位址，`docs/re/011`）

## 3. 熱鍵（`-cheat` 打開才有）

| 鍵 | 行為 |
|---|---|
| F5 | HP 與能量補到各自的上限 |
| F6 | 把敵人 HP 設成 1（只在戰鬥畫面有意義；不在戰鬥時什麼都不做） |

- 兩個鍵都攔在前端，不送進遊戲（`apps/psychicwar.Intercepted`）。
- 按下時畫面顯示一行提示（與 F10 同一套 toast）。
- **F6 的安全條件**：只有在「敵人 HP 目前 ≥ 1 且 ≤ 999」時才寫，避免在非戰鬥畫面亂寫。
  不符條件就顯示「現在不是戰鬥」。

## 4. 驗收

1. 單元測試：`Cheat` 的純函式部分——上限與現值的換算（HP 超過上限時取上限、上限是 0 時不動）。
2. 實跑（Xvfb）：`-cheat` 啟動，在戰鬥狀態按 F5，接著 F10 存檔，用 probe 讀狀態檔：
   HP ＝ 上限、能量 ＝ 上限；按 F6 後敵人 HP ＝ 1。
3. 反向對照：**不給 `-cheat`** 時按 F5／F6，記憶體不變（同樣用 F10 存檔比對）。

## 5. 不做

- 無敵、瞬移、跳關、改經驗值。
- 存檔裡的作弊標記（存檔是原版格式，不動它）。
