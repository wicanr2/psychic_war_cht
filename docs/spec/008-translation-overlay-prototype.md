# 008：轉譯疊字層雛形（第一句中文）

狀態：**READY**
日期：2026-09-17
對應：issue #20（放大畫布＋疊字層）、#21（CJK 點陣字）；文本檔 `docs/spec/007`；印字路徑 `docs/re/014`；前端 `docs/spec/006`；dosgolem 規格 `200-hook-register-write`

## 1. 目的

在前端的放大畫布上，把 `FONT.BIN` 路徑印出的**一行文字**換成中文：原版照常執行、照常畫英文，轉譯層在同一個位置蓋上中文。
本版只做驗證路線：撞牆訊息（`I_MENUH.BIN:0530`）與出發平台的目的地選單（`I_MENUH.BIN:09F0`＋選項）。
其他來源（小字型、`CODE` 內嵌、`PW.EXE` 字串、敵人名、地點名）不在本版。

## 2. 做法的選擇

| 做法 | 取捨 | 本版 |
|---|---|---|
| 在畫字前把 AL 換成空白（`SetRegs`），疊字層只畫中文 | 英文不會出現；但背景與前景色號拿不到，畫面內容變成一片空白，疊字層沒辦法用內容追蹤捲動與覆蓋 | 不用 |
| **英文照畫，疊字層先用背景色蓋掉該行再畫中文** | 顏色直接從該行的英文像素取；該行的像素內容可以當「疊字還有效嗎」的指紋；疊字層失效時英文仍看得見 | **採用** |

`SetRegs`（dosgolem `200-hook-register-write`）保留給需要改寫原版行為的地方。

## 3. 規格

### 3.1 位址（遊戲專屬，`apps/psychicwar`）

| 名稱 | 位址 | 用途 |
|---|---|---|
| 定長字串迴圈頭 | `0161:6289`（`sub_16799`） | BX ＝ 目前字元指標（ds）、CH ＝ 本行剩下字數；游標 `cs:610E` |
| 單字元畫字呼叫 | `0161:6158`（`sub_16629` 內 `call sub_1884B`） | 這時 BX 仍是呼叫端的字元指標；`[SS:SP+8]` 是 `sub_16629` 的返回位址，`628E` 表示來自 `sub_16799` |
| 訊息框捲動一步之後 | `0161:6276`（`sub_16783` 的 `retn`） | 訊息框 x 8–135、y 88–119 的內容已上移 2 像素 |
| 區域編號 | 線性 `0x16966`（字組） | `I_MENUnn` 的 nn |
| 載入位置 | `I_MENUH` 線性 `13A16`（E00h bytes）、`I_MENUnn` 線性 `12316`（B00h bytes） | `docs/re/017` §2 |

### 3.2 換算 key 與建立疊字

- 在 `6289`：若 BX 不是上一次命中的 BX＋1，這是**新的一行**。起點線性 `DS×16＋BX`：
  - 在 `I_MENUH` 範圍 → 檔名 `I_MENUH.BIN`；在 `I_MENUnn` 範圍 → `I_MENU%02d.BIN`（區域編號）；其他 → 不處理。
  - 偏移 o 依序找 key `o`（訊息第 1 行、選單提問第 1 行）、`o−16`（第 2 行）、`o−6`（選項標籤）。
  - 找到 key 但 `translation` 為空：**不疊字**，記一筆「缺譯文」（每個 key 記一次）。
  - 有譯文：依 key 的種類排版（§3.3），取出這一行對應的中文，建立一筆疊字：左上角 `(X×4, Y×4)`（游標 `cs:610E` 高位元組 X、低位元組 Y）、格數 ＝ CH、字串指標範圍 `[BX, BX＋CH)`，狀態「印字中」。
- 在 `6158`：返回位址是 `628E` 且 BX 等於某筆「印字中」疊字的最後一個字元指標 → 該筆改為「待定色」。

### 3.3 排版

- 一格 ＝ 原版一個 8×8 字格。中文、全形符號、ASCII 一律一個字元佔一格。
- 訊息與選單提問：兩行，格數 16、15；選項：一行 10 格。
- 譯文依序填滿第 1 行再換第 2 行；譯文裡的 `\n` 強制換行。放不下的字截掉並記一筆「譯文過長」。
- 一行的中文靠左對齊，剩下的格子留空。

### 3.4 定色、失效與捲動

- **定色**（每一幀，機器停下來之後）：「待定色」的疊字讀該行 `CH×8 × 8` 像素的色號（`Indexed()`）：出現最多的色號是背景、第二多是前景（只有一種時前景 ＝ 背景）。
  RGB 從同一幀的 `ScreenRGB()` 在該色號第一次出現的位置取。同時記下這塊色號陣列的指紋（FNV-1a 64 位元），狀態改「顯示中」。
- **失效**：「顯示中」的疊字每幀重算指紋；連續 3 幀不同就移除（連續 3 幀的門檻避開捲動只做到一半時被誤判）。
- **捲動**：`6276` 觸發時，左上角落在訊息框（x 8–135、y 88–119）裡的疊字 y −2；移到 y < 88 的移除。指紋不變（內容跟著搬）。
- **覆蓋**：新疊字的矩形與舊疊字重疊時，舊的移除。

### 3.5 繪製

- 疊字層是 `320×scale × 200×scale` 的 RGBA 圖，每幀重畫，畫在放大後的原版畫面上面。
- 每筆「顯示中」：整個矩形填背景色；每格的 24×24 字模（`font/cjk24.bin`）以前景色畫，一格的畫布大小 ＝ 8×scale；scale ≠ 3 時以 `scale/3` 做最近鄰縮放（scale 必須是 3 的倍數，否則停用疊字層並警告）。
- 字型子集沒有的字：畫空格，記一筆「缺字」。

### 3.6 前端參數與紀錄

| 參數 | 預設 | 意義 |
|---|---|---|
| `-text` | `text` | 文本檔目錄；空字串 ＝ 停用轉譯層 |
| `-font` | `font/cjk24.bin` | 中文字型子集 |
| `-text-log` | 空 | 轉譯紀錄（JSON Lines）：`stamp`（key、行、位置、格數、顏色）、`missing-translation`、`too-long`、`missing-glyph`、`drop` |

### 3.7 字型（`tools/font/bake.sh`）

- 漢字：倚天中文系統 3.53 的 24 點明體 `STD.24M`（ETUNPACK 解壓，`tools/font/etunpack.py`）；Big5 分區索引見 knowledge-base `eten-bitmap-font`。
- 其他字元（標點、ASCII）：Noto Sans CJK TC（SIL OFL 1.1）以 22 pt 點陣化成 24×24。
- 輸出 `font/cjk24.bin`：`PWCJK24\0`、u32 字數、每字 u32 碼點 ＋ u8 來源 ＋ 72 bytes。
- ⚠ **倚天字模的散布授權未確認**。本 repo private 期間放子集；公開前要換成授權清楚的字型或取得授權（#36 一起處理）。

## 4. 驗收

1. 單元測試（`apps/psychicwar`，不需要 X）：
   - 排版：`這裡無法前進。` 在 16／15 格排成第 1 行 7 字、第 2 行空；18 字的譯文第 1 行 16 字、第 2 行 2 字；32 字記「譯文過長」。
   - key 換算：線性 `13A16＋530h` → `I_MENUH.BIN:0530`；`13A16＋540h` → 同一則第 2 行；`12316＋4F0h`、區域 1 → `I_MENU01.BIN:04F0`。
   - 捲動：訊息框內的疊字 y −2；y 從 88 移到 86 的被移除；框外的不動。
   - 失效：指紋連續 2 幀不同仍保留，第 3 幀移除；中間恢復一次就重新計數。
   - 定色：8×8 格內 50 個色號 0、14 個色號 11 → 背景 0、前景 11。
2. 實跑（Xvfb，`tools/frontend-overlay-check.sh`，scale 3）：
   - 撞牆：`-load-state workplace/overlay/wall-before.state`，送 Up，等轉譯紀錄出現 `I_MENUH.BIN:0530` 的 `stamp` 後截圖。
     期望畫面**不用前端自己的紀錄算**：以原版（probe 跑同一狀態、同一按鍵）的 320×200 色號畫面找出這一行英文所在的 8×8 字格列與背景、前景 RGB，
     把譯文依 §3.3 排版、以字型子集與這兩個顏色畫出期望的 `128×3 × 8×3` 區塊；與截圖同一區塊**逐像素相同**。
   - 目的地選單：`-load-state workplace/overlay/launchpad-before.state`，等提問與 5 個選項的 `stamp` 都出現後截圖；提問第 1 行與每個選項各比一次。
   - 反向對照：把 `I_MENUH.BIN:0530` 的譯文清空（暫存副本），同一流程截圖：該區塊與原版英文畫面放大 3 倍逐像素相同，紀錄有一筆 `missing-translation`。
3. 其他畫面不受影響：沒有疊字時（`-text ""`）與原版畫面逐像素相同（沿用 `docs/spec/006` §4 第 2 項）。

## 5. 不做

- 小字型路徑、`62A2`／`62AF` 的字串、敵人名與地點名（下一版，接 `docs/spec/007` §6.2 的換算）。
- 中文行寬自動調整、斷詞、雙行合併重排（例：把第 1 行放不下的字搬到第 2 行以外的地方）。
- 選單反白、游標箭頭的中文化。
- 字型授權的最終方案。
