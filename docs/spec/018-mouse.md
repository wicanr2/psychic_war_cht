## 1. 原版不支援滑鼠

解壓後的 `PW_UNP.EXE` 裡，IDA 認得的 `INT` 指令共 93 處，號碼分布是
`21h` 74、`10h` 9、`1Ah` 5、`15h` 3、`20h` 1、`08h` 1——**沒有 `33h`**（滑鼠驅動的介面）。

`docs/re/001` 記過「執行檔裡有 1 處 `CD 33`，4 億步內沒有執行」，那是 byte pattern，不是指令：
同一份文件與 `CLAUDE.md` 都寫明 **byte pattern 計數不能當 `INT` 證據**。以 IDA 的指令表為準。

結論：滑鼠是**轉譯層自己提供的**功能，不是在模擬原版的行為。這一點要寫進說明頁——
玩家會問「原版有滑鼠嗎」。

## 2. 做什麼

畫面右上角的操作面板有四個項目（`docs/re/023`、`docs/re/024`）。點下去等於按對應的鍵：

| 熱區 | 面板項目 | 送出的鍵 |
|---|---|---|
| (168, 0)–(232, 24) | `ADVANCE`／前進（上箭頭） | `Up` |
| (168, 24)–(200, 48) | `LOOK ASIDE` 的左箭頭 | `Left` |
| (200, 24)–(232, 48) | `LOOK ASIDE` 的右箭頭 | `Right` |
| (168, 48)–(232, 64) | `TURN`／向後轉（下箭頭） | `Down` |
| (168, 64)–(232, 80) | `ESC OPERATION`／選單 | `Escape` |

座標是**原版像素**（320×200）；前端把滑鼠位置除以 scale 再比對。
熱區涵蓋箭頭與文字，不只文字區塊——玩家會點箭頭。

`LOOK ASIDE` 那一行左右各半：原版那一行兩端各有一個箭頭（`◄ LOOK ASIDE ►`），
左半是向左看、右半是向右看。

## 3. 怎麼送

點下去送 `KeyDown`、放開送 `KeyUp`，與鍵盤走同一條路（`apps/psychicwar.ScanCode`）。
**不模擬「按一下」**：原版有些操作要按住（例如戰鬥時的攻擊），維持按住／放開的語意才不會漏掉這類用法。

熱區之外的點擊不做任何事（不吃掉、也不送鍵）。滑鼠移動不送任何東西——原版沒有游標。

## 4. 驗收

1. **點選與按鍵走到同一個狀態**：同一個狀態檔起跑，一邊用滑鼠點「前進」、一邊按 `Up`，
   各自 F10 存檔，兩份存檔的觀測變數（`lin:16966` 起 52 bytes）**逐位元組相同**。
2. 反向對照：點熱區外面（例如畫面左下角），觀測變數與沒點時相同。
3. 四個熱區各自對到正確的鍵（單元測試：座標 → 鍵）。
4. 熱區的邊界：剛好在邊上的點與差一像素在外面的點，結果不同（單元測試）。

## 5. 不做

- 游標圖示（原版沒有游標；Ebiten 用系統游標）。
- 拖曳、滾輪、右鍵。
- 迷宮畫面上的點擊移動（那要知道畫面上哪裡對應到哪個方向，是另一件事）。
