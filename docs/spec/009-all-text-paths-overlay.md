|---|---|---|---|

## 2. 疊字幾何

| 字型路徑 | 原版字格 | 放大 3 倍 | 中文字型 | 字模偏移 | 字模倍率 |
|---|---|---|---|---|---|
| A（`FONT.BIN`） | 8×8 | 24×24 | 24×24（`font/cjk24.golemfnt`） | (0,0) | scale ÷ 3 |
| B（小字型） | 6×7（字 6×6、行距 7） | 18×21 | 16×15（`font/cjk16.golemfnt`） | (1,3) × scale ÷ 3 | scale ÷ 3 |

- 小字型的量測：`02-match` 的說明區塊，第 1 行字在 y 89–93、x 從 100 起每 6 像素一字；行距 7；區塊背景色號 1、前景 14。
- 字型：漢字與全形符號用倚天 3.53（24 點 `STD.24M`；16 點 `STDFONT.15`＋`SPCFONT.15`），其他字元用 Noto Sans CJK TC 點陣化。檔案格式 `GOLEMFNT`（dosgolem 規格 `202` §2.1）。

## 3. 排版與透明格

- 一個字元一格（全形、半形都一格）。行寬：

  | 種類 | 行寬 |
  |---|---|
  | `message`、`menu` | 16、15 |
  | `option` | 10 |
  | `block` | 每行 20（3 行或 8 行） |
  | `line`、`names`、`place`、`enemy-name`、`inline` | 原文可印字元（≥ 20h）的個數 |

- **透明格**：譯文某格是半形空白、而且原文同一格也是空白時，這一格不填背景、不畫字、不列入指紋。
  用途：輸入框（`ENTER YOUR NAME:` 的 `[        ]`、`INPUT FILE NAME:`、ESP 輸入）裡玩家打的字由原版畫出來，疊字不會蓋掉，也不會因為輸入變動而失效。
  譯者在這類行要讓方括號與空白留在原文的格子位置。
- **保留原文**：譯文與原文（文本檔表示法，含 `{XX}`）完全相同時，不建疊字，原版像素照常顯示；不算缺譯文，也不檢查格數。用於密碼字串、擬聲詞、單一符號等。
- `tools/text_extract.py lint` 以同一套行寬檢查「譯文過長」與非 Big5 字元。

## 4. 路徑細節

共同：區域編號取線性 `0x16966` 的字組（`I_MAP%02d`、`I_ENMY%02d` 的 nn）。游標 `cs:610E`（高位元組 X、低位元組 Y，×4 像素）。

### 4.1 A2：`62A2`（ds:BX 到 0）

- 迴圈頭逐字命中；新的一行 ＝ 位址不是上一次 ＋1（`xlate.LineTracker`，不看剩餘字數）。
- 起點線性 `DS×16＋BX`，往後讀到 00 得到位元組串；含 < 10h 的控制碼就不疊（紀錄 `unsupported-control`）。格數 ＝ ≥ 20h 的位元組數；游標在第一個 ≥ 20h 的位元組處（顏色碼不移動游標）。
- 來源：
  - `CODEnn` 載入區 `11C16`–`12315`（700h）：key ＝ `CODE<nn>.BIN:<起點−11C16>`；nn 取最近一次載入（見 §4.4）。
  - `CODEH` 載入區 `14816`–`15A15`（1200h）：key ＝ `CODEH.BIN:<起點−14816>`。
  - 腳本緩衝區 `16816`–`16915`：含字母或 ≥ 80h 的字碼時，以內容比對 `I_MAP<區域>.BIN` 的地點名稱（去掉尾端空白後相同）；只有數字與空白的不處理。
- 畫完：`6158` 命中、返回位址 `62AD`、`BX−1` 等於最後一個可印字元的位址（`62A2` 迴圈先 `inc bx` 再呼叫）。

### 4.2 A3：`62AF`（cs:BX 到 0）

- 同 4.1，位址是段 `0161` 偏移。
- 來源：偏移 `3A4C` → 以內容比對 `I_ENMY<區域>.BIN` 的敵人名稱；其他 → key `PW.EXE:cs:<偏移>`。
- 畫完：返回位址 `62BB`、`BX−1` 等於最後一個可印字元。

### 4.3 B：小字型 `B0F1`

每字一次命中；AL ＝ 字碼、SI ＝ X、DI ＝ Y（原版像素，已經是這個字的位置）、返回位址 `[SS:SP]`。依返回位址取字元指標 p（段 `0161` 偏移）：

| 返回位址 | 呼叫者 | p |
|---|---|---|
| `B02A` | `B016` 60 bytes 區塊 | BX |
| `07A0` | `0788` 故事 160 bytes | BX |
| `07D1` | `07C1` 到 0 的行 | BX |
| `0BB1`、`1259` | 製作群 | BX − 1 |
| `653A` | 盟友名 | BX |
| `654E` | 基地名 | DX |
| `B055` | 輸入回顯、選擇游標 | 不處理 |
| 其他 | — | 紀錄 `unknown-caller` |

- p 落在某則 `PW.EXE` 條目 `[位址, 位址＋寬度)`：行 ＝ (p − 位址) ÷ 行寬、欄 ＝ 餘數。
  - 欄 ＝ 0：建立這一行的疊字，左上角 (SI, DI)，格數 ＝ 行寬。
  - 欄 ＝ 行寬 − 1：這一行改為待定色。
- `B07D` 區塊的第 1 行是從 20 bytes 的行（`8851`、`88A8`、`88D1`、`88FA`、`8923`）複製來的：欄 ＝ 0 時讀記憶體 `cs:B07D` 的 20 bytes，以內容比對那 5 則，用比到的那則的譯文。
- 同一個位址重畫時，新疊字取代舊的（重疊移除）。

### 4.4 最近一次載入的 `CODEnn`

`CODEnn` 固定載入在 `11C16`，每次換區域重新載入。以區域編號推 nn（`CODE<區域>.BIN`，區域 0–11 對應 `CODE0`–`CODE11`）。
依據：`docs/re/017` §2 的讀檔紀錄（區域 0 載 `CODE0`、區域 1 載 `CODE1`）。

### 4.5 重複則

`same_as` 不為空的一則，用根 key 的譯文。

### 4.6 訊息框捲動

`sub_16770` 呼叫 4 次 `sub_16783`（`6273`），每次把訊息框上移 2 像素；這一步是逐列搬動顯存，前端每幀跑的機器時間短時會跨好幾幀。

- `6273` 命中：標記「捲動中」；訊息框內的疊字在標記期間不定色、不檢查指紋（dosgolem `xlate.Layer.Frozen`）。
- `6276`（retn）命中：清除標記，疊字上移 2 像素，出框的移除。
- 依據：前端 Xvfb 的 `wall` 情境，未凍結時第 1 行疊字在第 3 步捲動中被判為 `changed` 移除（2,774 個像素露出英文）；`pwstep` 每 16.7 ms 定一次色，沒有碰到。
- 捲動中途存的狀態檔不保存標記；讀回後最多多出一次失效計數，不影響結果。

## 5. 工具

- `apps/psychicwar`：`Translator` 改用 dosgolem `xlate`，掛上述四個位址；原本的 `apps/psychicwar/overlay` 移除。
- `cmd/pwstep`：逐步操作（dosgolem 規格 `201`）加上轉譯層：
  `pwstep -orig <目錄> [-load-state in | -new] -do "<動作>" -save-state out [-shot out.png] [-scale 3] [-text text] [-text-log out.jsonl]`。
  疊字層存在 `<out>.xlate.json`，下一步 `-load-state` 時一起讀回；截圖是放大後的原版畫面加上疊字層。
- `tools/overlay_check.py`：情境改成資料檔 `tools/overlay_cases.json`（狀態、動作、參照步數、要檢查的 key 與行）；
  原版位置搜尋支援兩種字型（小字型字模由 `PW_UNP.EXE` 的 `cs:B13D` 指標表讀出）；期望區塊依 §2 的幾何與透明格畫。

## 6. 驗收

1. 單元測試：
   - 透明格：譯文「`  [  ]`」配原文「`  [  ]`」的格子透明，字元格不透明；透明格變動不影響指紋。
   - A2／A3／B 的來源換算：用表列位址造出各種呼叫，換算到正確 key、行、欄（含 `B07D` 第 1 行的內容比對、腳本緩衝區的地點名稱、敵人名稱）。
   - `lint` 行寬：每種 `kind` 各一則剛好放得下、多一字過長。
2. 逐像素（`pwstep`＋`tools/overlay_check.py`，期望值由原版畫面推算）：每條路徑至少一則，差 0：
   - A2：方位 `CODEH.BIN:02B4`（`07-first-play`）、地點名稱 `I_MAP01.BIN:0228`（`16-sivad`）；
   - A3：敵人名稱 `I_ENMY00.BIN:0052`（`08-encounter`）；`PW.EXE` 內嵌字串一則（實跑能到的，例如投降訊息）；
   - B：區塊 `PW.EXE:cs:65E5`（`02-match`）、有輸入框的 `PW.EXE:cs:8AEF`（`06-name` 之後輸入名字，透明格內是原版輸入的字）、盟友名與基地名（`03-protection`）。
   - 反向對照：每條路徑拿掉一則譯文，該行與原版英文放大 3 倍差 0。
3. 前端（Xvfb）：A（`wall`，含訊息框捲動）、B（`match`）各一個情境用 `tools/frontend-overlay-check.sh` 再驗一次，確認 Ebiten 合成與 `pwstep` 相同。

## 7. 不做

- 控制碼 < 10h 的字串（只記錄）。
- 故事的逐字打字效果（一行畫完才蓋上中文）。
- 選單反白、游標箭頭。
