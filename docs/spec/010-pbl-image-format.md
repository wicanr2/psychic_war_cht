# 010：`.PBL` 圖檔格式與貼圖位置

狀態：**READY**
日期：2026-09-18
對應：issue #18（含文字的圖清冊）、#25（中文替換層）
證據與數字：`docs/re/023`；解碼工具 `tools/pbl.py`

## 1. 範圍

原版 26 個 `.PBL` 檔（共 537 張圖）的容器格式、壓縮、像素排列，以及「哪一張圖畫在畫面哪個位置」的取得方式。
不在範圍：替換圖的格式與疊上去的機制（`docs/spec/011`）。

## 2. 容器

```
u16 T                 表長（bytes）＝ 第 1 張圖的偏移；張數 ＝ T ÷ 2
u16 offset[T/2]       每張圖在檔案中的絕對偏移（遞增）
```

最後一張圖到檔尾都是它的資料。原版讀檔時先讀前 200h bytes 當偏移表，再 `LSEEK` 到 `offset[圖號]`
讀 1388h（5,000）bytes（`sub_189BF`，`0161:84AF`）——**所以單張圖的壓縮資料不超過 5,000 bytes**，
全部 537 張都符合（最大 4,941）。

## 3. 每張圖

```
u8  w                 寬 ÷ 8
u8  h                 高 ÷ 8
u8  map[16]           CGA 4 色對照表（EGA 不用，見 §5）
…                     RLE 資料
```

解壓後長度固定 ＝ `w × h × 32` bytes ＝ `(w×8) × (h×8) ÷ 2`，**一個 byte 兩個像素**
（高半位元組在左），整張圖逐列排列，沒有圖塊或位元平面。

### 3.1 RLE（`sub_18B76`，`0161:8666`）

```
前一個 ← 讀 1 byte
迴圈：
    這一個 ← 讀 1 byte
    若 這一個 == 前一個：            # 重複段
        次數 ← 讀 1 byte
        輸出「前一個」次數次          # 兩個相同的 byte 本身不輸出
        前一個 ← 讀 1 byte
    否則：
        輸出「前一個」
        前一個 ← 這一個
    輸出滿 w×h×32 bytes 就停
```

### 3.2 顏色

EGA 0Dh 下色號就是解壓後的半位元組值（0–15），不轉換。
`map[16]` 只在 CGA／Tandy 4 色模式用：`sub_18C62`（`0161:8752`）把一個 byte 的兩個半位元組各查一次表；
`sub_18B76` 與 `sub_18A98` 都在顯示模式旗標 `cs:863E` 等於 2 或 5 時跳過這個轉換，EGA 走的就是這條路。
旁證：26 個檔的對照表值域都在 0–3。

## 4. 載入與貼圖

| 常式 | `0161:` | 用途 |
|---|---|---|
| `sub_189BF` | `84AF` | 開檔、讀偏移表、`LSEEK`、讀圖、關檔，複製到 `BX` 指的緩衝區 |
| `sub_18A7C` | `856C` | 載入後直接畫到畫面（`sub_18A98`，邊解壓邊畫） |
| `sub_18B76` | `8666` | 載入後解壓到 `BX` 指的緩衝區（之後由別的常式貼上畫面） |
| `sub_18C62` | `8752` | 4 色模式的色號轉換 |

呼叫慣例：

- `AH` ＝ 檔案索引（0–25，表在 `cs:915B`，每筆是「1 byte 磁片編號 ＋ ASCIIZ 檔名」的位址）
- `AL` ＝ 圖號
- `CH`、`CL` ＝ 貼圖位置，**各乘 4 就是像素座標**（`sub_18A98`：`si = CH×4`、`di = CL×4`），與印字游標 `cs:610E` 同一套單位

檔案索引表（磁片編號取自同一筆的第一個 byte）：

| 索引 | 檔案 | 索引 | 檔案 | 索引 | 檔案 |
|---:|---|---:|---|---:|---|
| 0–11 | `enemy00–11.pbl` | 16 | `screen.pbl` | 21 | `end0.pbl` |
| 12 | `ally.pbl` | 17 | `open.pbl` | 22 | `end1.pbl` |
| 13 | `menu.pbl` | 18 | `room0.pbl` | 23 | `logo.pbl` |

| 15 | `fight.pbl` | 20 | `over.pbl` | 25 | `kgdlogo.pbl` |

## 5. 工具

`tools/pbl.py`（走 `tools/py.sh`）：

- `list <檔案…>`：每張圖的偏移、長度、尺寸、壓縮率。
- `dump <檔案> <輸出目錄> [圖號…]`：每張圖輸出 `.idx`（色號陣列，前 4 bytes 是寬高）與 `.png`（EGA 預設 16 色）。
- `find <畫面.png> <檔案…>`：拿解出的色號去畫面上找位置，回 `(x, y)` 或 `null`。

## 6. 驗收

1. 26 個檔、537 張圖全部解得開：吃掉的輸入 bytes 等於該張圖在檔案裡的長度（±2，最後一段重複的計數 byte），輸出長度等於 `w×h×32`。
2. 逐像素對原版：`SCREEN.PBL` 的第 0、1、2 張在實跑畫面 `07-first-play` 的 (0,0)、(0,40)、(0,80) 完全相同（`find` 回這三個座標）。
3. 反向對照：把 RLE 的重複段次數改成「次數＋1」重解，第 2 項找不到位置（回 `null`）。
4. 位置換算：`sub_116E0`（`logo.pbl` 第 0 張，`CH=1Ah`、`CL=06h` → (104, 24)）與 `menu.pbl` 第 0 張（(160, 4)）在實跑畫面上找到的位置相同。

## 7. 不做

- 4 色模式的畫面（本專案只支援 EGA 0Dh）。
- 把圖寫回 `.PBL`（替換層不改原版檔案，見 `docs/spec/011`）。
