# 015：F6 自動地圖

狀態：**READY**
日期：2026-09-18
對應：issue #32
前置：位址 `docs/re/011`（區域、座標、朝向）；熱鍵 `docs/spec/012`；即時存檔 `docs/spec/012` §4

## 1. 資料從哪裡來

**不解地圖檔**（`I_MAP` 的牆壁位元至今沒解，`docs/re/013` §3），改成**走過才記**的自動地圖：
前端每一幀讀腳本變數，走到新的格子就記下來。

| 值 | 線性位址 | 說明 |
|---|---|---|
| 區域 | `0x16966` | 0–11，每個區域一張地圖 |
| X | `0x16968` | 往西減 1 |
| Y | `0x1696A` | 往北減 1 |
| 朝向 | `0x16970` | 0 北、1 東、2 南、3 西 |

- 只在「三個值都在合理範圍」時才記：X、Y ≤ 63，區域 ≤ 11。載入畫面、戰鬥轉場時那幾個字組可能是舊值或垃圾。
- 記的是**走過的格子**，不是牆壁：地圖畫出來是一張點陣圖，看得出走過的路徑與目前位置。

## 2. 畫面

F6 開關；開著的時候蓋在畫面上（與 F1 說明頁同一層，兩者不同時顯示——後按的蓋前面的）。

- 版面：格子 12×12 放大後像素，左上角從畫布的 (24, 24) 起，最多畫 32×32 格（原版座標 0–31）。
- 顏色：走過的格子亮灰（色號 7 的 RGB）、目前所在的格子白色、其餘不畫（透明）。
- 目前位置另外畫一個朝向記號（上下左右各一個，用 `↑→↓←`，字型子集已經有）。
- 標題列：`區域 <n>　座標 (<x>, <y>)　已走 <n> 格`。

## 3. 保存

- 記在前端的記憶體裡，**每個區域一份**。
- F10 即時存檔時一起存成 `<scratch>/quick.map.json`（schema `psychic-war-automap/1`，內容是 `{"<區域>": [[x, y], …]}`）；
  F11 讀回。檔案不存在時當作空的，不影響讀檔。
- 原版存檔（`.DAT`）不動。

## 4. 驗收

1. 單元測試：`AutoMap.Note` 只在合理範圍內記；同一格記兩次只算一格；每個區域分開；快照往返（JSON）後內容相同。
2. 實跑（Xvfb）：從 `07-first-play` 走 3 步再按 F6，畫面上：
   - 目前格子的顏色是白色，位置 ＝ 由記憶體算出的格子；
   - 走過的格子數 ＝ 實際走過的相異座標數（標題列的數字）；
   - 開關 F6 前後的記憶體（`lin:16966` 起 52 bytes）相同。
3. 反向對照：沒走過的格子在畫面上是背景色（不是走過的顏色）。

## 5. 不做

- 牆壁、門、樓梯（`I_MAP` 的格式沒解）。
- 跨區域的整合地圖、縮放、捲動。
- 在地圖上標地點名稱（要另外解地點與座標的對應）。
