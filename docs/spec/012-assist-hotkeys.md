# 012：輔助熱鍵 F4 說明、F5 切換語言、F10 即時存檔

狀態：**READY**
日期：2026-09-18
對應：issue #29（F1）、#30（F2）、#31（F10）
前置：前端 `docs/spec/006`；疊字 `docs/spec/009`、`011`；dosgolem `199-live-session-api`（狀態檔）、`202-translation-overlay`（疊字層快照）

## 1. 範圍

前端（`cmd/psychicwar`）的輔助熱鍵。這些鍵都**不送進遊戲**（`apps/psychicwar.Intercepted`），
所以遊戲狀態不受影響；自動地圖不在本文件（`docs/spec/015`）。

⚠ **F1、F2、F3 是原版自己的功能鍵，不可以拿來做輔助功能**（使用者實測 2026-09-19，
issue #42）。輔助熱鍵一律從 **F4** 起算，F9 也留給原版。
`scanCodes` 要有 `F1=0x3B`、`F2=0x3C`、`F3=0x3D`——少了掃描碼，就算不攔也送不進遊戲，
症狀是「按了沒反應」而不是報錯。

| 鍵 | 功能 |
|---|---|
| F4 | 開／關說明頁 |
| F5 | 切換中文／英文原文 |
| F6 | 自動地圖（`docs/spec/015`）|
| F7／F8 | 作弊，要 `-cheat` 才開（`docs/spec/014`）|
| F10 | 即時存檔 |
| F11 | 即時讀檔 |

F10 存、F11 讀是兩個鍵：同一個鍵兼兩用要先按修飾鍵，玩家在戰鬥中容易按錯。

## 2. F5 切換語言

- 切到英文：疊字層不畫（原版像素照常顯示）。切回中文：畫。
- **轉譯層照常運作**（掛鉤照攔、疊字照建、`Frame` 照跑），只是不畫；所以切回來的時候畫面立刻是正確的中文，不必重跑。
- 不動遊戲記憶體、不送按鍵。
- 狀態記在前端；F10 的存檔要記下目前是哪一種語言，讀檔後沿用。

## 3. F4 說明頁

- 覆蓋整個畫面（放大後的畫布），內容是固定文字，畫在疊字層之上；再按一次 F4 關閉。
- 遊戲**照常執行**（時間不停）：說明頁只是畫面上的一層，關掉之後畫面接續，記憶體與不開說明頁時相同。
- 版面：放大後 960×600（scale 3）以 24×24 的中文字型排版，每行最多 38 字、最多 22 行；顏色固定（背景色號 0、前景色號 15），不取畫面顏色。
- 內容（`apps/psychicwar/help.go`，本 repo 專屬）：
  - 操作：↑ 前進、←→ 轉向、↓ 向後轉、Esc 選單、空白鍵攻擊（**要按住**）。
  - 提示：每走一步 HP 與能量會慢慢回復；太空站裡有治療室；**發射台（Launch Pad）才能選目的地，降落平台（Landing Pad）不行**（`docs/re/022` §4 第 6 條）。
  - 原版的功能鍵：F1、F2、F3（說明頁要列出來，玩家現在看不到這些）。
  - 輔助鍵：F4 說明、F5 中文／英文、F6 地圖、F10 存檔、F11 讀檔。
  - 防拷：說明書的配對題，空白作答也會過（`docs/re/003`）。
  - 說明書只摘要，不轉錄（CLAUDE.md 硬規則）。

## 4. F10／F11 即時存檔

檔案 `<scratch>/quick.state`（dosgolem 狀態檔）與 `<scratch>/quick.state.xlate.json`（疊字層快照）加一份 `<scratch>/quick.json`：

```json
{
  "schema": "psychic-war-quicksave/1",
  "golem": "<dosgolem 版本字串>",
  "exe_sha256": "<PW.EXE 的 SHA-256>",
  "text_sha256": "<text/ 全部 *.json 內容的 SHA-256>",
  "language": "zh",
  "saved_at": "<RFC3339>"
}
```

- F10：存狀態、疊字層快照與上面的中繼資料；畫面上顯示一行提示（兩秒後消失）。
- F11：三個檔都在、`golem` 與 `exe_sha256` 相同才讀；不同就**拒絕**並顯示原因，不動目前的遊戲。
  `text_sha256` 不同只警告（換了譯文照樣能讀，疊字層快照裡的字可能是舊的）。
- 讀檔後重新登記圖檔疊字的 watcher（dosgolem 規格 `203` §2.3）。

## 5. 驗收

1. 單元測試：中繼資料的版本比對（相同才可讀、`exe_sha256` 不同要拒絕並說明是哪一項不符）；說明頁排版（超過行寬或行數時建置期就報錯）。
2. F5（Xvfb）：
   - 中文 → 英文：畫面與 `cmd/step` 跑同一狀態、同一動作的原版畫面**逐像素相同**。
   - 英文 → 中文：畫面與切換前的中文畫面逐像素相同。
   - 切換前後遊戲記憶體相同（狀態檔的記憶體區段比對）。
3. F4（Xvfb）：任何畫面按 F4 都會出現說明頁、再按一次消失；開關前後記憶體相同；說明頁本身與期望值（由字型排版推算）逐像素相同。
4. F10／F11（Xvfb）：存檔後繼續玩幾步，按 F11 讀回，畫面與記憶體和存檔時相同；把 `quick.json` 的 `exe_sha256` 改掉之後 F11 拒絕讀且遊戲繼續。
5. 反向對照：F2 在英文模式時，中文疊字的那幾塊與原版英文差 0（確認真的沒畫）。

## 6. 不做

- F3 自動地圖（#32）、作弊（#33）。
- 多個存檔槽（只有一個 `quick`）。
- 說明頁的分頁與捲動（一頁放得下）。
