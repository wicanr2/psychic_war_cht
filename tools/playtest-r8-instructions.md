# 抽測試玩指令（第 8 輪）：看招牌與道具圖鑑

你是玩家，接著之前的進度玩。目的是**抽兩段路徑，確認畫面上是中文**（包含這一輪新做的「畫在圖上的字」），
不必從頭玩到結局。

## 起點與工具

```
tools/playstep.sh play3 new  "<動作>"          # 第一步（如果還沒有）
tools/playstep.sh play3 next "<動作>"          # 接著跑
tools/playstep.sh play3 from <NNN> "<動作>"    # 從第 NNN 步重來
```

- 每一步印出截圖路徑（`workplace/playtest/play3/NNN.png`）與轉譯紀錄，**每一步都要 Read 截圖**。
- 動作：`tap:<鍵>`、`hold:<鍵>:<毫秒>`、`wait:<毫秒>`、`type:<文字>`，逗號分隔。
  鍵名 `Return`、`Space`、`Esc`、`Up`、`Down`、`Left`、`Right`、`Backspace`、字母、數字。
- 遊戲很慢：按鍵後等 2–4 秒；一步不要超過 15 秒遊戲時間；看不到結果的連續按鍵最多 3 個。

## 兩段抽測

| 段 | 要做的事 | 上限 |
|---|---|---|
| A | **進一個有招牌的房間**：在薩瑪或賽瓦德找到牆上有告示的房間（危險、警衛、電梯、資料、逃生口之類），走進去看清楚 | 150 步 |
| B | **打開道具圖鑑**：Esc → 看道具，或撿到道具時出現的說明頁，看它的文字 | 100 步 |

每段都記錄：畫面上的字是不是中文、有沒有破版（中文蓋歪、蓋掉招牌邊框、蓋掉別的美術）、有沒有英文殘留。

## 等級不夠就用作弊鍵

第 7 輪的抽測卡在等級（3 級角色打不過賽瓦德的敵人）。這一輪**允許用作弊**把角色撐住：
`tools/playstep.sh` 跑的是 `pwstep`，沒有作弊鍵；遇到打不贏的戰鬥時，**改用 `from` 回到戰鬥前，繞開那條路**，
不要反覆戰死。真的必須打贏才過得去時，在紀錄寫明「這裡被等級擋住」。

## 判讀規則

- **捲動中或轉場中的畫面不要拿來判斷有沒有英文**：訊息框捲動時新的一行還是原版英文，捲完才會變中文（已知、不是缺陷）。
  要判斷就多等一步讓畫面靜止。
- 轉譯紀錄出現 `missing-translation`、`too-long`、`missing-glyph`、`unsupported-control`、`unknown-caller` 就是問題，記下來。

## 紀錄

寫 `workplace/playtest/play3/record.md`（繁體中文），每 10 步至少更新一次：逐步表、問題表（步、類型、描述、截圖）、摘要
（每段步數與是否完成、卡住次數、重來次數、畫面上還有英文的地方，分「遊戲文字」與「圖片上的字」）。

問題類型：`英文殘留`、`圖片文字`、`排版`、`翻譯`、`操作`、`轉譯紀錄`、`其他`。

## 邊界（嚴格遵守）

- 只寫 `workplace/playtest/play3/` 底下的檔案；不改其他檔案；不 git commit／push。
- 不要自己跑 docker；Python 一律走 `tools/py.sh`；不動 `~/.cache/`、`~/.claude/`、其他 repo。
- 做完回報：兩段的步數與是否完成、卡住與重來次數、問題清單（前 15 條）、畫面上還有英文的地方。
