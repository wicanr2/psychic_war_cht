# HD 主題：細密美術的繪製指示

給畫圖工具的指引。正式範圍與READY／DRAFT狀態以 `docs/spec/024-hd-theme.md` 為準，證據入口為 `docs/re/038-hd-theme-feasibility.md`。

幾何元素（箭頭、框線、鍵帽、格線、儀表）由 `tools/hd/render.py` 從基元描述向量重畫，
**不在本文範圍**。本文處理人物、敵人、房間與其他需要重繪的細密美術。

---

## 1. 這是什麼工作

《銀河超能力戰記》（Psychic War: Cosmic Soldier 2，工画堂 1987，DOS 英文移植 1989）
繁體中文化的 HD 主題。原版畫面是 EGA 320×200 十六色，轉譯層把它整數倍放大到 960×600，
在放大後的畫布上疊高解析度素材。

**要的是「基於原版重新繪製」，不是放大。**
構圖、姿勢、配色、氣氛照原版；線條、造型、細節重畫成 960×600 該有的密度。

## 2. 硬性約束

| 項目 | 規定 |
|---|---|
| 尺寸 | **必須剛好等於下表的輸出尺寸**，不能多一像素。模型畫完要裁切縮放到位 |
| 文字 | **一個字都不要畫**。畫面上的中文由疊字層另外畫，英文更不能留 |
| 色彩 | **不限十六色**。疊層是全 RGB，可以用漸層與中間色 |
| 抖色 | 原版用黃白交錯棋盤格表現中間色調。**重繪要把它畫成真正的中間色**，不要保留棋盤格 |
| 邊界 | **不能超出矩形**。超出去會蓋到迷宮視野與訊息框 |
| 背景 | 原版是純黑的地方畫純黑 `#000000`，不要透明也不要深灰 |
| 風格 | 1987 年日式科幻動畫的賽璐珞質感。**不要**現代 3D 渲染、不要照片寫實、不要厚塗 |

## 3. 常駐背景素材

座標是原版的 320×200 像素座標；輸出是它的 3 倍。

### 3.1 人物（`girl`）

| | |
|---|---|
| 原版矩形 | x 232–319、y 0–151（88×152） |
| 輸出尺寸 | **264×456** |
| 參照 | `workplace/hd/art-ref/girl.png` |

畫面右側的常駐人物立繪，從開機到結局一直在。

粉紅／洋紅長髮的女性，穿桃紅色緊身衣配青藍色護甲片（肩、腰、膝），
左手握一支圓柱狀的能量匣，半側身站姿，背景純黑。

重繪要處理的：頭髮的分束與高光（原版只有三階）、護甲的金屬反光、
緊身衣的布料轉折、皮膚的中間色調（原版是黃白棋盤格抖色，要畫成真正的漸層）。

**姿勢、服裝配色、能量匣的位置照原版。** 臉的五官可以畫細，但要維持 1987 年的畫風。

使用者定案 2026-10-01：人物放在原版 `(232,0)`，不為避開框線而縮小或平移；
最終可見區域止於 `y=143`，前方控制台與框線按原版位置遮住人物，不能畫成浮在介面上的獨立貼圖。
框線位於人物前方；中文與遊戲內容的位置照原版。合成原型及核對入口見 `docs/re/038` §31。

| 輸出尺寸 | **360×192** |

畫面中段的機艙壁面。灰白面板、桃紅與青色的管線、紅色指示燈、

### 3.3 底部機械帶（`mech-bot`）

### 3.4 整屏外框（`chrome`）

| | |
|---|---|
| 原版矩形 | 全畫面 x 0–319、y 0–199 |
| 輸出尺寸 | **960×600** |
| 參照 | `workplace/hd/art-ref/chrome.png`（原版 3 倍） |
| 功能遮罩 | `workplace/hd/art-ref/chrome-mask-preview.png` |

整個畫面的框架：機艙壁面、管線、面板邊框、儀表、指示燈、分隔線。
把 3.2 與 3.3 的機械帶包含在內——**這一張交出來之後，`mech-mid` 與 `mech-bot` 就不用另外畫。**

#### 對位是第一優先

**功能區塊的邊界必須落在跟原版完全相同的像素行列。** 對不準的話整張報廢，
因為框線一偏，遊戲畫上去的訊息與數值就會壓在框上。

四個必須對齊的區塊（原版座標，×3 是輸出座標）：

| 區塊 | 原版矩形 |
|---|---|
| 指令面板（黑底） | x 146–319、y 0–121 |
| 訊息框（黑底） | x 0–144、y 86–122 |
| 狀態列內部（黑底） | x 80–193、y 121–141 |
| 迷宮視野（黑底） | x 0–319、y 123–199 |

做法建議：拿參照圖當底，逐區塊替換視覺處理，不要整張重新構圖。
畫完自己用 ImageMagick 跟參照圖比一次，確認上面四個矩形的邊界沒有位移。

#### 功能遮罩

`chrome-mask-preview.png` 裡**洋紅色（`#FF00FF`）的區域是遊戲要畫東西的地方**。
那些像素交出來之後會被 `tools/hd/mask.py` 改成全透明，所以：

- 那些地方畫**純黑 `#000000`**，不要畫裝飾（畫了也會被丟掉，而且會讓你誤判成品）。
- 洋紅佔全畫面 60.4%，真正要畫的是剩下的 39.6%。

#### 不含人物

右側人物（3.1 的 `girl`）**不要畫進這一張**，那塊畫純黑，由 `girl.png` 另外疊上去。

### 3.5 其他sprite

使用者已於2026-10-01定案：敵人、盟友、房間、迷宮視野、小圖塊及戰鬥效果都納入HD，完整範圍見024 §1.1／§6。

- 每張以實際解碼的原版矩形為準，輸出寬高為原版的三倍。敵人24×32身體輸出72×96，16×16小圖塊輸出48×48；其他尺寸依實際來源，不能只看檔名猜。
- 同角色的所有姿勢沿用同一套造型、比例、配色及線條。保留原版手腳位置、動作差異及配件數量，不將像素相似分組當成角色語意證據。
- 小尺寸優先保留清楚輪廓與主要色區，避免新增細管、螺栓或關節，縮圖後須能辨讀。
- 提示詞要列像素座標時，先用 `tools/pbl.py` 的獨立解碼及來源PNG核對，依整張原圖寬高換算；不能只憑多格預覽估位置。ENEMY00 #2手部座標勘誤入口為研究038 §75的【HD-ENEMY00-ARMPOS-01】。
- 舊生成提示詞不證明原版動作。重畫每個姿勢前獨立看該圖號的單格參照；不可把同組首姿勢的手臂套到末姿勢。ENEMY00 #5左手抬高的勘誤入口為研究038 §76的【HD-ENEMY00-POSE5-LEFTARM-01】。
- 原生生成圖可依固定圖格切出並縮至指定尺寸；不能靠平移、縮小角色或重排姿勢修正生成偏差。
- 未知用途與尚未READY的效果或迷宮資料契約只製作候選。接入前依024對應限定契約審查，正常遊戲動作及重疊驗證另行完成。
- 原生圖、完整提示詞、來源與輸出雜湊保存於 `workplace/hd/redraw/` 的版本化檔案，不覆寫既有候選；研究038索引每批入口。

## 4. 不畫的東西

- **標題 Logo（`PSYCHIC WAR` 美術字）沿用原版。** `docs/spec/011` §6 已經定案
  標題美術字不重製（`LOGO.PBL`／`KGDLOGO.PBL` 兩張都沒疊中文）。
  `SCREEN.PBL` 上的 Logo 是同一個字標，照同一個決定辦。
- 指令面板的箭頭、鍵帽、框線、紅色格線：這些是幾何元素，由程式向量重畫。

## 5. 交回來的格式

```
workplace/hd/art-in/
  girl.png        264×456
  chrome.png      960×600   ← 交了這張就不用 mech-mid／mech-bot
  mech-mid.png    360×192   （chrome 的替代方案，兩者擇一）
  mech-bot.png    960×48
```

PNG、8 位元 RGB 或 RGBA。背景素材用 `tools/hd/check.py` 核對；其他PBL批次用 `tools/hd/verify_batch.py`。尺寸與解碼合格只證明技術格式，不代表美術驗收。

## 6. 驗收

1. 尺寸剛好相符。
2. 畫面上沒有任何文字。
3. 放回原版矩形之後，構圖與原版對得上（同一個人物在同一個位置、同一個姿勢）。
4. 實跑一次，四個檢查點的畫面正常，遊戲狀態不變（`docs/spec/024` §6）。
5. 反向對照：主題關掉時畫面與原版逐像素相同。
6. 其他sprite逐姿勢核對造型、比例、輪廓、主要色區及動作關係；再驗正常玩家呈現、清除、重疊及載回。單張生成圖或候選數量不算完整HD完成。
